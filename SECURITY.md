# Security Policy

Please do not report security vulnerabilities in public issues or pull requests.
Use the repository's private vulnerability reporting feature under the GitHub Security tab instead. Include the affected endpoint, reproduction steps, and potential impact. Do not include live credentials or customer data.

Rotate any exposed credential immediately and remove it from deployment settings and Git history as appropriate. A Git commit that deletes a secret does not revoke it.

Only the latest deployed version is supported with security fixes.
